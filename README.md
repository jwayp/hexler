# HEXler

A 16×16 hexadecimal logic puzzle game inspired by Sudoku.

HEXler challenges players to complete a 16×16 grid using sixteen symbols (0–9 and A–F), with each 4×4 region following the same logic.

## Features

- 16×16 puzzle grid
- Sixteen hexadecimal symbols (0–9, A–F)
- Multiple difficulty levels
- Game timer with pause and resume
- Progress saving
- Game history and completion statistics

## Technology

- React
- JavaScript
- Vite
- CSS

## Run Locally

Requirements: Node.js and npm.

npm run dev
